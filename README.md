# Пока открыт мост

В браузере доступен первый сценарий эвакуации с закрытым водосбросом. Выберите транспорт на карте или в панели приказов, назначьте соседний узел и нажмите «Выполнить ход». «Ждать» снимает приказ выбранной машины. После закрытия обеих переправ появятся итоги по районам. Кнопка «Повторить» начинает новую партию.

Используем Phaser 4.2.1, TypeScript 5.9.3 и Vite 8.3.8. Проект проверен с Node.js 24.13.0 и npm 11.6.2.

## Запуск

Из папки проекта:

```powershell
npm ci
npm run dev
```

Откройте локальный адрес из терминала. Для проверки собранной версии:

```powershell
npm run build
npm run preview
```

## Проверки

```powershell
npm test
npm run test:browser
```

Тесты правил воспроизводят оба плана со стр. 4 геймдизайн-документа. Браузерные тесты требуют Chrome и Microsoft Edge. Они проходят план А до итога и повтора, проверяют конфликт автобусов на мосту, клики Phaser после изменения размера окна, клавиатурный ввод и запуск сборки из подпапки.

Правила находятся в `src/game/turn.ts`, а карта, транспорт и сроки закрытия в `src/game/scenario.ts`. Закрытия следующего хода входят в события с номером хода, на котором вступают в силу.
