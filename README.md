# Пока открыт мост

Пробная карта этапа 0. Нажмите «Убежище» или «Развязка» на карте. Кнопки под картой работают с клавиатуры и показывают выбранный узел.

Используем Phaser 4.2.1, TypeScript 5.9.3 и Vite 8.3.8. На этапе 0 проверяли с Node.js 24.13.0 и npm 11.6.2.

## Документация

- [Геймдизайн прототипа](docs/game-design.md) — карта, правила хода и контрольные планы эвакуации.
- [План реализации](docs/implementation-plan.md) — этапы работы, критерии завершения и плейтест.

## Запуск

Из папки проекта:

```powershell
npm ci
npm run dev
```

Откройте локальный адрес из терминала. Для проверки собранной версии:

```powershell
npm run build
npm run preview
```

## Браузерные проверки

```powershell
npm run test:browser
```

Тестам нужны установленные Chrome и Microsoft Edge. Они проверяют WebGL, клики в обоих размерах окна, клавиатурный ввод, отсутствие внешних запросов и работу сборки из подпапки `/stage-0/`.

## Проверки правил хода

```powershell
npm test
```

Тесты запускаются в Node.js и воспроизводят [планы эвакуации А и Б](docs/game-design.md#два-плана-эвакуации). Правила этапа 1 находятся в `src/game/turn.ts`, а карта, транспорт и сроки закрытия в `src/game/scenario.ts`.

`createInitialState()` начинает новую партию. `validateTurn()` проверяет приказы. `advanceTurn()` возвращает новый снимок и события хода. Если приказ отклонён, функция возвращает исходный снимок и причины отказа. Закрытия следующего хода входят в список событий с номером хода, на котором вступают в силу. `getRouteForecast()` позволяет сравнить режимы водосброса заранее. `getEvacuationReport()` показывает вывезенных, ожидающих и пассажиров в транспорте по каждому району.
