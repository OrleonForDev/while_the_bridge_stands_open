# Пока открыт мост

Выберите транспорт на карте или в панели приказов, назначьте соседний узел и нажмите «Выполнить ход». «Ждать» снимает приказ выбранной машины. Прогноз с первого хода показывает, когда по мосту и на пароме ещё можно проехать.

На третьем ходу выберите режим водосброса. Прогноз на карте меняется сразу, а выбор вступает в силу после нажатия «Выполнить ход». После закрытия обеих переправ появятся итоги по районам. Кнопка «Повторить» начинает новую партию.

Используем Phaser 4.2.1, TypeScript 5.9.3 и Vite 8.3.8. Проект проверен с Node.js 24.13.0 и npm 11.6.2.

## Запуск

Из папки проекта:

```powershell
npm ci
npm run dev
```

Откройте локальный адрес из терминала. Для проверки собранной версии:

```powershell
npm run build
npm run preview
```

## Пакет для плейтеста

На Windows выполните в репозитории:

```powershell
npm ci
npm run package:playtest
```

Архив появится в папке release. Его можно передать целиком. Внутри уже собранная игра, [короткая инструкция](handoff/START-HERE.txt), [форма первого плейтеста](handoff/PLAYTEST.txt) и запуск через start.cmd. Игроку нужен Node.js 22.12 или новее и Chrome либо Edge. Версия игры указана внизу страницы.

Организатор может передать архив без контрольных маршрутов ниже. Попросите игрока сначала сыграть самостоятельно, а сразу после подтверждения хода 3, если вы наблюдаете за игрой, спросите, что изменилось для моста и парома. После партии отметьте, начал ли игрок повтор сам. Для группы из десяти ориентир — не менее семи верно объясняют оба изменения и не менее шести добровольно начинают повтор.

## Контрольные маршруты

Каждая строка — приказы на один ход. Прочерк означает «Ждать». Первые три хода одинаковы, а на третьем выберите режим.

| Ход | Автобус А1 | Автобус А2 | Паром |
| --- | --- | --- | --- |
| 1 | Больница | Развязка | Набережная |
| 2 | Развязка | Убежище | Убежище |
| 3 | Убежище | — | Набережная |

### План А · оставить водосброс закрытым

| Ход | Автобус А1 | Автобус А2 | Паром |
| --- | --- | --- | --- |
| 4 | — | — | Убежище |
| 5 | — | — | Набережная |
| 6 | — | — | Убежище |

В убежище 90 из 108 человек — 18 из больницы, 18 из школы и 54 с набережной.

### План Б · открыть водосброс

| Ход | Автобус А1 | Автобус А2 | Паром |
| --- | --- | --- | --- |
| 4 | Развязка | — | Убежище |
| 5 | Больница | — | — |
| 6 | Развязка | — | — |
| 7 | Убежище | — | — |

В убежище 90 из 108 человек — 36 из больницы, 18 из школы и 36 с набережной.

## Проверки

```powershell
npm test
npm run test:browser
```

Тесты правил воспроизводят оба плана со стр. 4 геймдизайн-документа. Браузерные тесты требуют установленные Chrome и Microsoft Edge. Готовая сборка запускается из подпапки, и оба плана проходят до итога и повтора в каждом браузере при размерах 1920 × 1080, 1280 × 720, 1024 × 576 с коэффициентом плотности 1,25 и 390 × 844. Проверки также охватывают клики по карте после изменения размера окна, клавиатурный ввод, смену прогноза до подтверждения, конфликт на мосту, звук и локальную загрузку ассетов.

Правила находятся в `src/game/turn.ts`. Карта, транспорт и сроки закрытия заданы в `src/game/scenario.ts`.
